# Money Ledger

A command-line money tracking application built with Java and Gradle.

## Current Features

- Interactive CLI menu
- Menu selection handling
- Gradle project structure

## Planned Features

- Add income
- Add expense
- View transaction history
- Categories
- File persistence
- Monthly summaries

## Tech Stack

- Java 25
- Gradle
- Git
- LazyVim
